# Đề xuất dự án – VolunteerLink

**Lĩnh vực:** Hoạt động xã hội / VolunteerTech.
**Ngữ cảnh:** Hoạt động tình nguyện tuyển người qua mạng xã hội, khó biết ca nào còn thiếu kỹ năng và ai đã xác nhận.

| Vấn đề | Giải pháp trong sản phẩm |
|---|---|
| P1. Thông tin phân tán | Danh sách cơ hội tập trung, có lọc theo lĩnh vực/kỹ năng; kiểm duyệt trước khi hiển thị |
| P2. Khó ghép đúng kỹ năng | Điểm phù hợp kỹ năng + lịch rảnh + kinh nghiệm (AI-1) |
| P3. Điều phối ca thủ công | Bảng ghép người, đồng bộ trạng thái ca, cảnh báo thiếu ca (AI-2) |
| P4. Khó ghi nhận đóng góp | Ghi giờ theo ca, hồ sơ giờ tình nguyện, tóm tắt tác động (AI-3) |

Mục tiêu O1–O7 xem đề BTL-24. Công nghệ: HTML5 ngữ nghĩa, CSS thuần (token + responsive), JavaScript thuần (DOM/sự kiện/biểu mẫu), LocalStorage làm CSDL giả lập.
